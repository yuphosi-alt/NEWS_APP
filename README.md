# NEWS_APP

ニュースを読む習慣がない人でも、社会の重要な動きを無理なく理解できるようにする、日本語のニュース解説・学習サービス。

## プロジェクトの目的

テレビやニュースサイトを日常的に見ない社会人に向けて、信頼できる公開情報を調査し、背景知識のない人にも伝わる自然な日本語で独自解説を届ける。ニュースを大量に並べるのではなく、「何が起きたか」「なぜ重要か」「生活や仕事にどう関係するか」を理解できることを重視する。

## 配信構想

- 朝便：毎日 6:30（日本時間）
- 夜便：毎日 18:00（日本時間）
- 朝便は前夜以降の重要な動き、夜便は当日の新しい動きと朝便以降の変化を優先する。
- 件数は固定しない。重要な新情報が少ない場合は無理に埋めない。
- 朝便と夜便で同じ説明を繰り返さず、続報は決定・結果・重要数字・方針転換・生活への影響がある場合に限って扱う。

## 初期検証の最優先事項

まず1週間の試作を行い、ライセンス契約なしで次の点を検証する。

1. 適法に利用できる公開情報から、重要ニュースを十分に収集できるか
2. 事実確認・複数ソース照合に必要な人手はどの程度か
3. 生成AIの利用費用はどの程度か
4. ニュースの正確性・網羅性・読みやすさを両立できるか

## 基本方針

- 記事本文や写真を無断転載しない。
- 公的機関・企業等の一次資料と、信頼できる報道を優先する。
- 独自の要約・解説を作成し、出典リンクを示す。
- 事実、見解、推測、未確認情報を区別する。
- 政治的中立性を保ち、刺激的な事件や芸能ニュースに偏らない。
- 仕様上の確定事項と、今後検証する仮説を区別する。
